# 商材設計ラボ / Knowledge Product Studio (仮称)

電子商材の作り方を学びながら、自分の商品企画を形にするWebサイトの初期版です。

## 現状

- 学ぶ：テーマ1,2,3,4,6の教材プレビュー、テーマ5の構成仮ページ
- 作る：商品マップ、商品設計シート、完成チェック
- 保存：localStorage、JSONエクスポート・インポート（ユーザーデータはサーバー非送信）
- SEO：静的記事別URL、固有title/description、内部リンクを実装。ただし公開前レビューのため全ページnoindex
- 未実装：ユーザー認証、同期、決済、Muse連携、note投稿、Analytics/SC連携

## 手元で起動

`python3 -m http.server 8000` をこのディレクトリで実行して `http://localhost:8000` へアクセス。静的ファイルのみで動作します。

## 記事の出典と編集状態

2026-11-01に提供された学習ハブのテーマ1,2,3,4,6のMarkdown原稿を資料に、新サイト向けに要点を再構成。原稿は本人による公開前レビュー前提。テーマ5は原稿未提供なので仮の概要だけ。

## 運営構成

- COS（既存の private repo）：運営者Brain、Knowledge、監査、記事企画の正本。**内容を直接公開しない**。
- 本リポジトリ：公開予定の教材と利用者向けアプリのソース。
- Vercel：静的ホスティング予定。
- 将来のユーザーデータ保管：独立したDB/認証基盤へ。GitHub commitをユーザー操作の保存先にしない。

1. ブランド名・サイトURL・運営者連絡先・プライバシーポリシーを確定
