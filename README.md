# 経験をカタチにするLab / Knowledge Product Studio

自分の経験を商品や役立つコンテンツへ変える考え方と、SEO・Webマーケティング・販売導線を段階的に学ぶWebサイトです。KPSは内部プロジェクト名で、現在の正式サイト名は「経験をカタチにするLab」です。

## 現状

- カリキュラム：/academy/ の8領域（商品企画・SEO・Webマーケティング・改善など）
- 実例研究：/academy/cases/ でCharacter Motion Studio記事と学習教材の実例を確認
- SEOの学習：/academy/seo/、非公式理解度チェック：/academy/check/（実在の検定とは無関係）

- 学ぶ：テーマ1,2,3,4,6の教材プレビュー、テーマ5の新規執筆レビュー版
- 考える：思考の整理室（問い、経験、理由、価値基準、選択肢、判断履歴）
- 作る：商品マップ、商品設計シート、完成チェック
- 保存：localStorage、JSONエクスポート・インポート（ユーザーデータはサーバー非送信）
- SEO：静的記事別URL、固有title/description、内部リンクを実装。ただし公開前レビューのため全ページnoindex
- 未実装：ユーザー認証、同期、決済、Muse連携、note投稿、Analytics/SC連携

思考ノートは別キー `kps-thought-v1`。JSONエクスポート・インポートは商品設計ボードと互換性を持たせず、勝手に移植しない。非公開COS Brainは公開KPSへ複製しない。

## 手元で起動

`python3 -m http.server 8000` をこのディレクトリで実行して `http://localhost:8000` へアクセス。静的ファイルのみで動作します。

## 公開前チェック

1. ブランド名・サイトURLの確定・運営者連絡先・プライバシーポリシーを確定
2. テーマ5の新規原稿およびテーマ1〜6を全て運営者が編集確認
3. すでに準備済みのsitemap.xml・canonicalを監査し、OG画像や運営者情報を整備した後、noindexを解除
4. 記事・スマホUI・保存/復元・各リンクを実機点検
5. 本番公開後にGoogle Search Consoleなどを接続
